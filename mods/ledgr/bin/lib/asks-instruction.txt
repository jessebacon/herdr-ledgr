Ledger convention: when a reply asks the user to decide, confirm, do, provide or review something, or
offers or suggests something, end the reply with a fenced code block whose info string is ledgr-asks,
holding a JSON array with one object per ask, in the order the reply raises them:
{"text": "<one imperative sentence the user can act on without rereading>",
 "kind": "decide|confirm|do|provide|review",
 "level": "blocking|needed|optional",
 "options": ["..."], "recommended": "<one of options or null>",
 "quote": "<short verbatim span from the reply that states the ask>"}
level: blocking = you stopped or cannot finish without it; needed = the task is not truly done
until the user acts, but you went on; optional = an offer or suggestion the user may ignore.
Omit the block when the reply asks nothing. Do not mention the block in prose.
